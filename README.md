# ImobLink-2.0
BackEnd
  Para rodar o backend da nossa aplicação você precisa ter o Java 21 instalado em sua máquina, estar com a porta localhost:5432 liberada para rodar o banco de dados e ter o PostgreSQL na versão 14.17 instalado na sua máquina (caso não tenha ainda, você pode instalar por esse link diretamente no site do psql: https://www.postgresql.org/download/).
  Tendo tudo isso em mãos, você deve criar um banco de dados com as seguintes características:
  Nome da database: imoblinkdb
  Usuário: imoblink
  Senha: imoblink
  E deve garantir todos os privilegios da database a esse usuário para que o Spring funcione da maneira correta e de acordo com o que já está pré-pronto no código backend.
